# 演示指南

面向评审的 8 分钟演示脚本。每个步骤都标注了**要展示什么**与
**背后的 PowerContext 证据在哪里**。

---

## 0. 演示前准备

```powershell
# 终端 1：启动 PowerContext
powershell -NoProfile -File qoder/scripts/start_powercontext.ps1 -Token "your-token" -OpenDashboard

# 终端 2：启动 StudyFlow 后端
powershell -NoProfile -File qoder/scripts/run_backend.ps1

# 终端 3：写入演示数据
python qoder/scripts/seed_demo.py
```

浏览器打开 <http://127.0.0.1:8080>。

---

## 1. 开场：普通聊天机器人做不到的事（1 分钟）

**话术**：

> 大多数 AI 学习助手只记得当前这轮对话，关掉窗口就忘了你是谁、哪里薄弱。
> StudyFlow 用 PowerContext 把你的学习记忆存到服务端。同一个学习者 ID，
> 换一台电脑、隔一个月再打开，它还记得你上次练的是什么、错在哪。

**操作**：点击左下角学习者 ID，改成 `student_demo_999`，页面数据清空；
改回 `student_demo_001`，数据全部回来。

**证据**：左下角标注「长期记忆由 PowerContext 提供」；
「记忆中心」页显示 Scope ID 与条目数。

---

## 2. 学习记录 → 真实写入（1.5 分钟）

**操作**：进入「学习记录」页，填写：

| 字段 | 值 |
| --- | --- |
| 课程 | 数据库系统 |
| 知识点 | 2NF 分解 |
| 题目 | R(A,B,C,D)，F={A→B}，是否满足 2NF |
| 我的答案 | 满足 |
| 正确答案 | 满足（但存在非主属性对码的部分依赖） |
| 本次练习结果 | 错误 |
| 自评掌握程度 | 2 |
| 学习笔记 | 只会背定义，不会判非主属性依赖 |

点击「保存学习记录」。

**要展示**：成功提示里出现**新的掌握度百分比**，以及
「已写入 PowerContext」。

**证据**：

* 提示文案：`学习记录已保存到 PowerContext，并已更新该知识点的掌握度。`
* 表格最右列出现真实的 `artifact_id`（形如 `art_7e337f42ae440e889d0a3772943bfd0`）
  与修订号 `r1`。
* 这些 ID 就是 PowerContext 返回的 artifact ID，不是前端编的。

---

## 3. 薄弱分析：规则说了算，不是拍脑袋（1.5 分钟）

**操作**：进入「薄弱分析」页。

**要展示**：

* 「BCNF 分解」被标为**急需加强**，掌握度 43%；
* 判定原因逐条给出依据：「累计练习 3 次、答错 2 次，答题正确率约 33%，
  自评掌握程度约 2.7/5，综合掌握度约 43%，最近几次的正确率比之前有提升」；
* 「证据」列写明「基于 3 次练习」；
* 下方「全部知识点掌握度」表里，**答对且自评良好的知识点没有被列为薄弱点**。

**话术**：

> 这一条是刻意的产品约束：一次答错不能让系统断定你长期不会这个知识点。
> 需要多次证据才会升到「急需加强」。而只做对一次、自评也好的知识点，
> 根本不会被列为薄弱点。这条规则有单元测试保护。

**证据**：`qoder/tests/test_unit_domain.py` 中的
`test_single_wrong_answer_is_not_a_high_severity_weakness` 与
`test_single_correct_answer_is_not_a_weakness`。

---

## 4. 复习计划：每条建议都能说清为什么（1.5 分钟）

**操作**：进入「复习计划」页。

**要展示**：

* 「推荐原因」框里引用的是**真实历史数字**；
* 「证据：基于 3 次练习」；
* 如果配置了模型服务，下方「针对性练习」会给出针对该知识点的题目，
  点击「显示答案」可以核对；
* **没有**配置模型时，这一块显示「还没有生成练习题」并说明原因——
  不用假内容填充。

**话术**：

> 「先复习 BCNF 分解」这句话不是模型随口说的，括号里的数字是后端
> 从 PowerContext 里读出来的真实记录。模型只负责在此基础上补充怎么练。

**证据**：`qoder/evidence/scenarios/` 与「记忆中心」页的原始条目。

---

## 5. 记忆中心：PowerContext 真的参与了业务（1.5 分钟）

**操作**：进入「记忆中心」页。

**要展示**：

* 「PowerContext 读取：正常」「PowerContext 写入：正常」；
* 学习者 ID、**PowerContext Scope**（`scp_...`）、Scope 标题、用户隔离键；
* 「已保存的学习档案」显示昵称、课程、目标、讲解偏好、重点关注；
* 最下方「PowerContext 记忆条目」表逐条列出：
  类型、Key、真实内容、`artifact_id`、修订号、状态。

**话术**：

> 这张表不是前端自己拼的假数据，每一行都是 PowerContext Server 里
> 真实存在的 Atomic Memory 条目，ID 就是服务端返回的 artifact ID。
> 评审可以拿这些 ID 去 PowerContext 的 Dashboard 里核对。

**证据**：同时打开 <http://127.0.0.1:8765/dashboard/home> 做对照。

---

## 6. AI 助手：先召回记忆，再回答（1.5 分钟）

> 需要先配置模型服务（见 `DEPLOYMENT.md` §5）。未配置时这一段改为
> 展示「AI 模型未配置」的明确提示——**这也是设计行为**。

**操作**：在「AI 助手」页输入：

> 我今天应该复习什么？

**要展示**：

* 回答下方显示「已使用 N 条长期记忆」与命中的记忆类型标签；
* 回答内容里提到你真实的薄弱知识点；
* 若记忆中没有相关信息，助手会明确说「我没有找到相关记忆」，而不是编造。

**话术**：

> 助手回答前会先向 PowerContext 检索你的记忆，把命中的内容拼成上下文，
> 然后在界面上明确标出这次用了几条记忆。它不是"声称"记得你，
> 而是把召回结果摆出来。

## 7. 隔离与持久化（1 分钟）

**操作**（终端 3）：

```bash
# 全新进程读取，验证持久化
python qoder/scripts/read_memory_once.py student_demo_001
```

**要展示**：输出的 `scope_id` 与页面上的一致，`record_count` 与页面一致。

**话术**：

> 这是另一个进程、另一条连接，没有任何内存缓存，读到的内容一模一样，
> 说明记忆确实在服务端而不是浏览器里。

再点左下角切换到另一个学习者 ID，展示数据清零。

## 9. 收尾：技术结合小结

| 赛题要求 | StudyFlow 的做法 | 现场可核对的位置 |
| --- | --- | --- |
| 实际使用 PowerContext | 长期记忆存储、跨会话读取、修订更新、Scope 隔离 | 「记忆中心」页 + `evidence/` |
| 不使用 seekDB | 未安装、未依赖、未创建 | 全仓库无 seekDB 依赖 |
| 不伪造数据 | 记忆来自真实 artifact；AI 未配置时明确提示 | `/api/system/status` + 界面提示 |
| 可复现 | 三个脚本 + 环境变量样例 + 文档 | `qoder/scripts/`、`qoder/docs/` |

## 10. 常见提问

**Q：为什么不用浏览器 localStorage 存学习记录？**
A：localStorage 换设备就没了，也不满足"长期记忆"的定义。这里 localStorage 只存
"当前选择的是哪个学习者 ID"这一个界面状态，所有学习记忆都在 PowerContext。

**Q：用户之间怎么隔离的？前端不是也能改吗？**
A：隔离在服务端。学习者 ID 映射到 PowerContext 的独立 Scope，所有读写都用
该 Scope 的 `scope_id`；Server 以 `enforced` 模式运行，未带令牌一律 401，
作用域访问还要过 `scope.read` / `scope.contribute`。前端改不动。

**Q：AI 会不会编造我的学习记录？**
A：回答只允许基于召回的记忆；召回为空时提示词明确要求回答"我没有找到相关记忆"。
而掌握度、薄弱判定、复习原因**完全不由模型计算**，而是从存储的练习记录算出来的。

**Q：一次答错会不会被判定成"不会"？**
A：不会。单次答错最多是"需要关注"，"急需加强"需要至少两次练习的证据。
只有一次正确且自评良好的知识点根本不会被列为薄弱点。有单元测试保护。

**Q：没有模型服务还能用吗？**
A：能。学习记录、薄弱分析、复习计划、记忆中心都由真实练习记录驱动。
只有 AI 回答与练习题生成会明确提示未配置，不会返回伪造内容。
